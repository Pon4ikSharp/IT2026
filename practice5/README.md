# Практична робота 1.4 — Облік документів

Проста інформаційна система для реєстрації та аналізу документів. Використано приклади викладача з теми 1.4–1.5.

## Що вміє програма

- Додавати документи: номер, тип, зміст, дата, статус.
- Показувати документи у таблиці.
- Шукати за номером або змістом і фільтрувати за типом.
- Змінювати статус та видаляти документ.
- Рахувати кількість документів за статусами.

## Технології

Python, Flask, PostgreSQL, HTML, CSS та звичайний JavaScript (без React).

## Структура

- app.py — сервер Flask і робота з PostgreSQL.
- schema.sql — створення таблиць документів та типів.
- templates/index.html — сторінка сайту.
- static/styles.css — оформлення.
- static/script.js — кнопки, пошук, таблиця, статистика.
- requirements.txt — потрібні бібліотеки.
- .env.example — зразок параметрів підключення.

## Як запустити на Windows

1. Встановити Python та PostgreSQL.
2. Завантажити папку practice5 та відкрити термінал у ній.
3. Виконати команду: pip install -r requirements.txt
4. У pgAdmin створити базу даних documents_db.
5. У Query Tool цієї бази виконати SQL із файлу schema.sql.
6. Скопіювати .env.example у .env та вписати пароль від PostgreSQL.
7. Запустити: python app.py
8. Відкрити адресу: http://127.0.0.1:5000

Файл .env з паролем не треба завантажувати на GitHub.

## Як це працює

1. Користувач вводить дані документа у форму HTML.
2. JavaScript надсилає їх у Flask через POST /api/documents.
3. Flask додає запис у PostgreSQL.
4. JavaScript отримує список через GET /api/documents.
5. На сторінці виводиться таблиця та проста статистика.

## API

- GET /api/document-types — типи документів.
- GET /api/documents — перелік документів.
- POST /api/documents — додати запис.
- PATCH /api/documents/ID/status — змінити статус.
- DELETE /api/documents/ID — видалити запис.
